## Risks
| # | risk | impact | mitigation / status |
|---|---|---|---|
| R1 | **Chain lifecycle**: Redstone shut down (2026-05-15); Blast shutting down (announced 2026-10-02, withdrawal deadline 2026-10-26); B3 archived; others (Mode/Zora/Cyber: L2BEAT "not even Stage 0", single permissioned proposer) could follow | wasted work, orphan nodes | only ship chains with a live public RPC and an active repo; re-check `eth_getBlockByNumber` age before each release. |
| R2 | Pinned op-reth/op-node carry the Superchain Registry **compiled in**: a new hardfork time on a family chain unknown to an older binary stops it following | outage at fork | bump pins together; CI check that the pinned tag's registry contains every family chain's latest `*_time`. World Chain uses its own `world-chain` binary — track its releases (v2.4.5, 2026-10-06; their compose pins op-node 1.19.5, we pin 1.19.9: INFERRED compatible). |
| R3 | `op-node` ≥ 1.19.1 has **no req/resp CL sync**; a node stopped for days can only catch up via EL peers or L1 re-derivation | long catch-up on chains with few EL peers (mode, zora, soneium, ink) | `consensus-layer` default + static peers (Ink/Lisk/Conduit) + snapshot; `execution-layer` only for unichain/world. |
| R4 | Snapshots from Alchemy/World/Gelato are **reth datadirs of unknown reth/storage version** vs pinned op-reth 2.6.0; checksums only for Gelato/OP Labs/Mantle | op-reth refuses to open the DB / silent corruption | Lisk Gelato snapshot: `db/database.version` = 2 (VERIFIED, read from the stream). Others INFERRED; script checks `db/mdbx.dat` or `static_files/`; add an `op-reth db version` probe + fall back to "sync from L1" with a clear status. Alchemy archives carry harmless extras (`proofs-storage/`, `p2p-peerstore.db/`, `start.sh`). |
| R5 | Public namespaces `debug,trace,txpool` + metrics `0.0.0.0` + op-node RPC `0.0.0.0` in the default unit | info leak / DoS | prod preset (FAMILY §8) + firewall; D5. |
| R6 | Alchemy discovery = scraping a Next.js page; the R2 account id in the URL may change | restore step fails → script retries every 5 min | regex on `…r2.dev/rpc-platform/<chain>/<net>/reth/reth-<ts>.tar.gz`; fall back to `snapshot_url`; log the failing page. |
| R7 | **1 s chains** (unichain, ink): default `sync→active` tip lag ≤ 3 blocks = 3 s vs a public RPC that itself lags 0-3 s → flapping | status noise | tip lag ≥ 6 blocks (or age-based) when blockTime = 1; needs a per-network knob in the facts YAML (INFERRED: not present today). |

| R11 | world-chain release filter: repo also publishes `proofs/v…` and `-rc` tags | wrong "latest" | `tagPrefix "v"` excludes `proofs/`; resolver test with the 2026-10 tag list (v2.4.5, v2.4.4, v2.4.3, proofs/v1.0.0-rc.5). |
